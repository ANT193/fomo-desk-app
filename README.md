# fomo-desk-app

Static app for a private paper/live trading desk (Plan B hosting, GitHub Pages).

**Owner-accepted exception to STEP 3:** the desk's data files live under a secret path `d/<DATA_PATH>/`.
Because this repo is public, that path is visible in this repo. The owner accepted this explicitly.
History is kept to a single force-pushed commit. The files carry no keys and no tokens.
